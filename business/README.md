# Business Context Scaffold

This literal tree is the canonical starting point for a new `context_type: business` folder. The hidden `.business-toolkit.json` manifest drives managed templates, Templater rules, saved hashes, and Iconize markers; it is not copied into business contexts.

The empty `.gitkeep` files make every standard folder visible in source control. Periodic templates, TaskNotes templates, generated Bases, context notes, and Excalidraw setup remain owned by the core vault bootstrap generator.

Use [[_system/docs/commands/Business Toolkit|Business Toolkit]] for creation, registration, synchronization, drift, and force behavior.
