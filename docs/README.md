## Context Vault template documentation

- `agent-operations.md`: detailed agent operations
- `_system/README.md`: Vault architecture and folder model
- `_system/docs/commands/README-reference.md`: Vault command reference
- `_system/bootstrap/README.md`: bootstrap, export, and upgrade

Repository-level architecture, bootstrap, release, and contributor contracts belong in `docs/`. End-user documentation delivered as part of the Vault remains within `_system/docs/` and is routed from this index.
