## VLC

| Shortcut | Action | Notes |
| --- | --- | --- |
| `G` | Push audio back / slow it down | Adjusts audio delay by 50 ms. |
| `F` | Bring audio forward | Adjusts audio delay by 50 ms. |
| `Cmd++` | Speed up video | Playback speed. |
| `Cmd+-` | Slow down video | Playback speed. |
| `Cmd+J` | Jump to time | The dialog says seconds, but `4:34` style input works. |
| `Cmd+Shift+L` | Mark loop start, mark loop end, then cancel loop | Press after jumping to start, then end, then a third time to cancel. |

## Da Vinci

ctrl + p - Timeline > Selection Follows Playhead (toggle depending) - ctrl + p

cmd shift ,swap clips left

cmd shift . - swap clips right

cmd shift drag, ripple insert no overwrite clip

cmd y - select ALL clips to left

alt y - all clips to right

alt shift cmd x - reset fusion composition (unfortunately only works for 1 clip at a time)

down/up arrow - start/end of next/previous clip

ctrl + shift + s - export current frame as still

ctrl + w / ctrl + s (switch between 1 and 2) or 8 / 9 - multicam cut

alt + 1/2/3/… - multicam switch

Cmd + shift + k - view keyboard shortcuts

ctrl + d - dynamic zoom view mode

cmt + t - transform view mode
