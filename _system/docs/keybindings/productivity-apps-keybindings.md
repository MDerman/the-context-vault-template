Notation: `Cmd` is Command, `Ctrl` is Control, and `Alt` is Option on macOS.

## Calendar

| Shortcut          | Action                                   | Notes                              |
| ----------------- | ---------------------------------------- | ---------------------------------- |
| `Cmd+Right Arrow` | Go to next day, week, month, or year     | Depends on Calendar view/settings. |
| `Cmd+Left Arrow`  | Go to previous day, week, month, or year | Depends on Calendar view/settings. |
| `Cmd+T`           | Go to today                              | Jump back to the current date.     |

## Raycast
| Shortcut                                               | Action                        |
| ------------------------------------------------------ | ----------------------------- |
| `Ctrl+Alt+Arrow Keys`                                  | Move/resize windows.          |
| `Ctrl+Alt+Enter`                                       | Maximize window.              |
| `Ctrl+Alt+I`, `Ctrl+Alt+U`, `Ctrl+Alt+J`, `Ctrl+Alt+K` | Window positioning shortcuts. |
| `Ctrl+E`                                               | Emojis.                       |
| `Alt+.`                                                | Raycast Notes.                |

| Alias/Snippet | Action          |
| ------------- | --------------- |
| `ns`          | Notion search.  |
| `sp`          | Spotify search. |
| `p`           | Phind search.   |

## Notion

| Shortcut     | Action                            |
| ------------ | --------------------------------- |
| `Ctrl+Cmd+P` | Command search / Search anywhere. |
| `Cmd+P`      | Search.                           |
| `Cmd+T`      | New tab.                          |

## Excel

| Shortcut | Action | Notes |
| --- | --- | --- |
