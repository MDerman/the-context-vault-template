Notation: `Cmd` is Command, `Ctrl` is Control, and `Alt` is Option on macOS.

## macOS And Global Automation

| Shortcut                     | Action                                           | Notes                                                                   |
| ---------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------- |
| `Ctrl+W`                     | Mute Spotify if playing and start/stop recording | Custom global automation.                                               |
| `Ctrl+Alt+Backtick`          | Play/pause Spotify only                          | Custom global automation.                                               |
| `Ctrl+Alt+H`                 | Help search                                      | Replaces `Cmd+Shift+/`; useful in Finder for actions like sort by kind. |
| `Cmd+Shift+?`                | Open Help search                                 | Native macOS Help menu shortcut.                                        |
| `Ctrl+Cmd+M`                 | Mute microphone                                  | Global microphone toggle.                                               |
| `Ctrl+Cmd+.`                 | New Warp tab here                                | Automator/Services shortcut.                                            |
| `Ctrl+Cmd+V`                 | Create new video project folder template         | Automator/Services shortcut.                                            |
| `Ctrl+Shift+Cmd+V`           | Create new media dump folder template            | Automator/Services shortcut.                                            |
| `Ctrl+Alt+Cmd+I`             | Create new Instagram post template               | Automator/Services shortcut.                                            |
| `Ctrl+1`, `Ctrl+2`, `Ctrl+3` | Move to matching Space                           | macOS Spaces shortcut.                                                  |
| `Ctrl+Left`, `Ctrl+Right`    | Move between Spaces                              | macOS Spaces shortcut.                                                  |
| `Ctrl+F1`                    | Start dictation / speech to text                 | Voice punctuation supports phrases like `new line` and `new paragraph`. |
| `Cmd+Shift+3`                | Copy text in screenshot to clipboard             | Custom Shortcuts app workflow.                                          |
| `Delete`                     | Delete right of cursor                           | `Backspace` deletes left of cursor.                                     |
| `Fn+Up`, `Fn+Down`           | Page up/down scroll                              | Useful in long pages and lists.                                         |
| `Alt+Cmd+L`                  | Launchpad                                        | Use `Cmd+Left/Right` to move between Launchpad pages.                   |
| `Alt+Cmd+D`                  | Toggle Dock hiding                               | Show/hide Dock.                                                         |
| `Cmd++`, `Cmd+-`             | Zoom in/out                                      | Works in many apps, including Finder.                                   |

## Finder

| Shortcut | Action | Notes |
| --- | --- | --- |
| `Shift+Cmd+G` | Go to folder or file path | Essential path jump. |
| `Cmd+Shift+.` | Show/hide hidden files | Fast visibility toggle. |
| `Cmd+Alt+C` | Copy selected item path | Also listed as `Cmd+Option+C`. |
| `Cmd+I` | Get Info | File or folder metadata. |
| `Cmd+Up` | Go to parent folder | Column/list navigation. |
| `Cmd+Down` | Open selected folder or file | Column/list navigation. |
| `Cmd+F` | Find | Finder search. |
| `Cmd+T` | Open a new Finder tab | Use Window > Merge All Windows to consolidate tabs. |
| `Ctrl+Cmd+F` | Full screen | Finder window full screen. |
| `Alt+drag column divider` | Resize all columns | Works well in column view. |
| `Double-click column divider` | Fit column width to contents | Column view cleanup. |
| `Arrow keys` | Navigate items | Pair with letter keys to jump to matching names. |
| `Spacebar` | Quick Look | Can trim videos from Quick Look/Preview workflows. |

## SteerMouse

| Shortcut / Button | Action | Notes |
| --- | --- | --- |
| `Cmd+Button 4` | Next tab | Runs `Cmd+Shift+]`; button closest to body. |
| `Cmd+Button 5` | Previous tab | Runs `Cmd+Shift+[`. |
| `Mouse 4` in VS Code | Back | Runs `Ctrl+-`. |
| `Mouse 5` in VS Code | Forward | Runs `Ctrl+Shift+-`. |

## Quick References And Ideas

- Apple dictation reference: https://support.apple.com/en-za/guide/mac-help/mh40695/mac
- Finder workflow video idea: https://www.youtube.com/watch?v=S689KZ3TBEc&list=WL&index=5
- Finder: hold down the back arrow to show history.
- Finder: spring-loading duration lives in Accessibility > Pointer Control.
- Finder: disable trackpad smart zoom if it interferes with faster two-finger workflows.
- QuickTime Player: use arrow keys to move frame by frame, then `Cmd+C` and `Cmd+V` to copy/paste a frame grab.
- VLC: use Video > Snapshot for screenshots.
- macOS: Remote Login can be enabled when needed.
