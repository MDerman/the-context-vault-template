# Agent Instructions

This repository is a public Context Vault template. Keep the Vault local-first, preserve user content, and follow the nearest `README.md` before changing a workflow.

- Use `[[Obsidian links]]` for internal Vault links.
- Keep normal notes concise and do not add an H1 that repeats the filename.
- Put tasks, projects, and other operating records under the owning context folder's `_obsidian/` tree.
- Put local state and generated reports under `_system/local/state/`; never commit credentials or private configuration.
- Read `_system/bootstrap/README.md` before install, export, or upgrade changes.
- Read `_system/docs/commands/README.md` before changing a `vault` command.
- The optional skill system is a separate product. A bootstrap install may place its public `_system/agents` tree here, but Vault upgrades must preserve it.

Keep changes simple, test the workflow that changed, and update the closest documentation when behavior changes.
